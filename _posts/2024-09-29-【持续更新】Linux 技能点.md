### 允许 root 用户 ssh 登陆

1. 配置文件

   ```
   vim /etc/ssh/sshd_config
   ```

   搜索下面配置项 `/Permit` 没有则添加

   ```
   PermitRootLogin yes
   ```

2. 重启服务

   ```
   systemctl restart sshd
   ```
