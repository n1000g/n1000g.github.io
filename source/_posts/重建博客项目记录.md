# 新建博客

新建一篇文章
```bash
# npx hexo new [layout] <title>
npx hexo new "测试文档"
```
- 默认的 layout 是 `post`，以后根据需要再学习添加新的 layout

渲染
```bash
npx hexo clean
npx hexo generate -b
# 可以本地启动 server 查看效果
# npx hexo server -p 8080
```

直接 git push 后续交给 Github Pages

# 搭建过程

## 01 新建 node 环境

新建一个独立的 conda 环境，后续只需要 activate
```bash
conda create -n node
conda activate node
```

Gemini 建议从 conda-forge 频道安装
```bash
conda install -c conda-forge nodejs
```

验证安装
```bash
which node
which npm
node -v
npm -v
```

## 02 照 Hexo 文档新建项目

安装 Hexo
```bash
npm install -g hexo
npm list -g
npx hexo version
```

新建 Hexo 项目
```bash
mkdir n1000g.github.io
hexo init n1000g.github.io
cd n1000g.github.io
npm install
```

修改 `_config.yml` Site 相关配置

还有一些无关的 git 操作

```bash
git config --global user.name n0b1000g
git config --global user.email n0b1000g@gmail.com
git config --global core.editor "vim"
git remote add origin git@github.com:n1000g/n1000g.github.io.git
git add .
git commit
git checkout -b fluid
git branch -D master
git push -u origin fluid
```


## 03 照 [Fluid 文档](https://github.com/fluid-dev/hexo-theme-fluid?tab=readme-ov-file#2-%E8%8E%B7%E5%8F%96%E4%B8%BB%E9%A2%98%E6%9C%80%E6%96%B0%E7%89%88%E6%9C%AC)设置主题

下载[最新 release 版本](https://github.com/fluid-dev/hexo-theme-fluid/releases)解压到 themes 目录，并将解压出的文件夹重命名为 fluid
```bash
tar zxvf hexo-theme-fluid-1.9.8.tar.gz
rm hexo-theme-fluid-1.9.8.tar.gz
mv hexo-theme-fluid-1.9.8 themes/fluid
```

修改 `_config.yml` 文件 theme 项为 `fluid`

创建「关于页」
```bash
npx hexo new page about
```

## 04 配置 Github Pages

在 Github Pages - Build and deployment 设置为 `fluid` 分支 `docs` 目录

配置里 `public_dir` 目录修改为 `docs`

然后把 docs 一起 push
